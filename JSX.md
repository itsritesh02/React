
## What is jsx and how does it differ from html

---


JSX stands for JavaScript XML. It is a syntax used in React that allows us to write HTML-like code inside JavaScript. JSX makes the code more readable and easier to create UI components. We can also use JavaScript expressions inside JSX using curly braces

---
### Example
---
function App() {
  const name = "Ritesh";

  return <h1>Hello {name}</h1>;
}
